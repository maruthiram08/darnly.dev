darnly

Connect your coding agent

For agents that run in the cloud (Claude, Codex or Cursor online), Darnly keeps your bugs in a private cloud inbox. Add it to your agent once, then say “fix the bugs in my Darnly inbox”.

The address to add:

https://api.darnly.dev/mcp

The first time, your agent opens a Darnly page that names the app asking for access. Check it, click Continue with Google, and use the same Google account you signed in with in the Chrome extension or the Mac app.

Before you start

Send bugs to the cloud inbox:

  • Chrome extension: in the Darnly panel choose In the cloud, then Sign in with Google.
  • Mac app: on the welcome screen choose In the cloud (or Cloud inbox in the menu bar menu) and sign in with Google.

Agent running on your own computer, in your project folder? You don't need any of this: Darnly saves bugs into .darnly/inbox in the project, and your agent reads them there.

Claude (claude.ai and the desktop app)

  1. Open Settings → Connectors → Add custom connector.
  2. Name: Darnly. URL: https://api.darnly.dev/mcp. Click Add.
  3. Click Connect and approve on the Darnly page.

Claude Code

claude mcp add --transport http darnly https://api.darnly.dev/mcp

Then run /mcp inside Claude Code, pick darnly and sign in.

Cursor

Open Settings → MCP → Add new MCP server, or add this to ~/.cursor/mcp.json:

{
  "mcpServers": {
    "darnly": { "url": "https://api.darnly.dev/mcp" }
  }
}

Cursor shows a Login button next to the server; click it and approve.

Other agents

Any agent that supports remote MCP servers with sign-in (OAuth) works: add https://api.darnly.dev/mcp as a streamable HTTP server.

What your agent can do

  • list_bugs: see the bugs waiting in your inbox.
  • get_bug: read one, with its screenshot and the picture of what it should look like, if you added one.
  • mark_fixed: mark it fixed with a line on what changed. Fixed bugs are deleted after 30 days.

It can't see anyone else's bugs. To disconnect an agent, remove the connector in that agent, or use “Sign out everywhere” in the Darnly panel. More in the privacy policy.
